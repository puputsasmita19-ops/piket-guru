1. Kriptografi & Manajemen Kredensial

Sistem menerapkan enkripsi Salted SHA-256 via Web Crypto API. Nilai salt heksadesimal 16 karakter di-generate secara acak per pengguna. PIN tidak pernah disimpan dalam bentuk teks polos. Sistem dilengkapi proteksi Brute-Force Lockout selama 15 menit jika terdeteksi 5 kali kegagalan beruntun.

3. Aturan Keamanan Firestore (Immutable Audit Logs)

Koleksi auditLogs dilindungi aturan mutlak di level cloud Firestore: allow create: if true; allow update, delete: if false;. Hal ini menjamin setiap log aktivitas tidak dapat diubah maupun dihapus oleh pihak manapun, memenuhi standar akuntabilitas kearsipan forensik.
